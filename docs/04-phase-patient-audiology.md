# المرحلة 4: ملف المريض وفحوصات السمع (قطاع السماعات)

**الهدف:** سجل طبي مبسط لكل مريض يشمل فحوصات السمع والمتابعة، مرتبط بالمبيعات والصيانة.

> ملاحظة: بيانات المرضى حساسة؛ طبّق صلاحيات الوصول والنسخ الاحتياطي.

## المهام

### 4.1 ملف المريض
- توسيع `customers` (أو جدول `patients` مرتبط به): تاريخ الميلاد، الجنس، المهنة، الشكوى، التاريخ المرضي، الحساسية، ملاحظات الطبيب.
- تبويبات في `CustomersView.vue` (تظهر في هذا القطاع فقط): بيانات، فحوصات، سماعات، فواتير، متابعات، مرفقات.

### 4.2 فحوصات السمع
- جدول `hearing_tests(id, patient_id, test_date, examiner_id, test_type, notes, attachments)`.
- جدول `audiogram_points(test_id, ear, conduction, frequency, db_value)`:
  - الأذن: يمين/يسار
  - النوع: هوائي/عظمي (مع/بدون masking)
  - الترددات: 250، 500، 1000، 2000، 4000، 8000 Hz
- نتائج إضافية: SRT، SDS (نسبة التمييز)، تقييم الطبلة (Tympanometry)، نوع ودرجة الفقد (سمعي توصيلي/حسي عصبي/مختلط؛ خفيف/متوسط/شديد...).
- مكوّن رسم **الأوديوجرام** (SVG): إدخال بالنقر أو بالجدول، X أزرق لليسار وO أحمر لليمين، والمقارنة بين فحصين.
- حساب درجة الفقد تلقائياً (متوسط PTA) كاقتراح قابل للتعديل.
- طباعة تقرير الفحص مع الرسم.

### 4.3 المتابعة والضبط
- جدول `followups(id, patient_id, device_id, type, due_date, done_date, notes)`.
- أنواع: ضبط السماعة، تنظيف، تغيير بطارية/قالب، فحص دوري.
- جلسات الضبط (Fitting): الإعدادات المبرمجة والملاحظات.
- تذكيرات المتابعة في لوحة التحكم، وقائمة المتأخرين.

### 4.3.1 القوالب (Earmolds)
- جدول `earmold_orders(id, patient_id, device_id, ear, mold_type, material, color, vent, impression_date, lab, sent_date, received_date, delivered_date, status, cost, remake_of, notes)`.
- الحالات: `أخذ قياس ← أُرسل للمعمل ← وصل ← سُلّم ← إعادة تصنيع`.
- الأذن (يمين/يسار/الاثنان)، وربط الطلب بفاتورة بيع (خدمة قالب) وبتكلفة المعمل.
- قائمة الطلبات المتأخرة عن المعمل، وتذكير تسليم، وإعادة التصنيع تحتفظ بالرابط للطلب الأصلي.

### 4.3.2 القوقعة (Cochlear Implant)
- جدول `implants(id, patient_id, ear, brand, internal_model, internal_serial, surgery_date, hospital, surgeon, processor_device_id, activation_date, notes)`.
- ربط معالج الصوت (كجهاز بالرقم التسلسلي) بالمريض، وتتبع ضمانه وملحقاته (ملف، كابل، مغناطيس، بطاريات).
- جلسات البرمجة (Mapping): `implant_sessions(id, implant_id, date, program_notes, thresholds_json, next_due)` مع مرفق ملف الـ map.
- متابعات خاصة: تأهيل سمعي ونطقي، وفحص دوري.
- تظهر في الملف والتبويبات لقطاع السماعات فقط.

### 4.4 مرفقات
- رفع ملفات/صور (تقرير خارجي، صورة أوديوجرام) وتخزينها محلياً بجوار قاعدة البيانات، مع ضمها للنسخ الاحتياطي.

### 4.5 الربط
- ربط الفحص بتوصية منتج في فاتورة البيع.
- ظهور تاريخ الفحوصات داخل طلب الصيانة.

## الملفات المتأثرة
`db.ts`، `types.ts`، `preload`، `CustomersView.vue`، `DashboardView.vue`، `PrintModal.vue`، مكوّنات جديدة: `AudiogramChart.vue`، `HearingTestForm.vue`، `FollowupsView.vue`.

## معيار القبول
- [ ] لا تظهر تبويبات المريض والفحوصات في قطاع `appliances`.
- [ ] إدخال فحص كامل ورسم الأوديوجرام وحفظه وطباعته.
- [ ] مقارنة فحصين لنفس المريض.
- [ ] طلب قالب يمر بكل حالاته ويظهر المتأخر عن المعمل.
- [ ] تسجيل زراعة قوقعة وربط المعالج وجلسة برمجة وتذكير الموعد القادم.
- [ ] التذكيرات تظهر في لوحة التحكم عند حلول الموعد.
- [ ] تتحكم الصلاحيات في من يرى السجلات الطبية.
